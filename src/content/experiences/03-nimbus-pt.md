#### Contexto

A Nimbus desenvolve soluções orientadas a dados para o setor energético, transformando preços de mercado, clima e dados hidrológicos em ferramentas de análise e visualização usadas por empresas de energia para apoiar operações e trading.

#### Conquistas

- Desenvolvi e mantive ferramentas web para a plataforma NIMBUS usando Django no backend e HTML, jQuery e Bootstrap no frontend.
- Trabalhei no desenvolvimento de ferramentas para análise e visualização de dados do mercado de energia, focando em preços, clima e condições hidrológicas.
- Desenvolvi um app mobile de treinamento em React Native para funcionários de usinas de cana-de-açúcar, junto com um dashboard web para acompanhar o progresso dos funcionários.
